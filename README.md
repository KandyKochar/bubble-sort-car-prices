# Bubble Sort — Car Price Sorter

A Java implementation of the bubble sort algorithm applied to a dataset of car prices, demonstrating sorting fundamentals.

## Overview
Implements bubble sort to sort car price data in ascending and descending order, with step-by-step output showing the sorting process.

## Features
- Bubble sort implementation for numeric arrays
- Car price dataset sorting
- Ascending and descending sort modes
- Step-by-step sort progress display

## Technologies Used
- **Language:** Java (JDK 8+)

## Project Structure
```
src/
+-- CarPriceSorter.java    # Bubble sort implementation with car price data
```

## Usage
```bash
javac src/*.java -d out/
java -cp out/ CarPriceSorter
```
